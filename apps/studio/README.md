# RevDev Studio

Desktop AI editor and agent coordination dashboard.

Built with Tauri 2 (Rust backend) + React 19 (TypeScript frontend).

## Features (planned)

- File tree, tabs, syntax highlighting, multi-cursor editing
- Built-in terminal pane (PTY via harness daemon)
- Agent coordination panel (live sessions, tasks, messages, file reservations)
- Local model management (inference-snaps, Ollama)
- Claude Code extension parity — native harness integration
